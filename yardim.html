Switched-Mode Power Supplies Help Page


View the project on GitHub

Switched-mode power supplies are systems widely used in energy conversion that efficiently convert electrical energy from one form to another. Such power supplies can convert the input voltage to the desired output voltage or current using various methods. Our calculation programs have been prepared to perform relevant calculations for different topologies and to assist people working in or interested in power electronics. This version has been published as a new release of the tool and some bugs have been fixed. It is aimed to fix other bugs with incoming feedback. Although the graphs do not provide completely accurate output like simulations made in Spice programs, they have been modified to give an idea about time variations, wave outputs, etc. ATAQ Advanced Technology Inc., 'www.ahmetturanalgin.com', Yasemin Tuğba Algın and Ahmet Turan Algın are not responsible for the consequences of incorrect choices that may arise from the program. For questions, notifications, and support, please contact yasemin.algin@ataq.com.tr. You can make suggestions for adding different topologies and present your recommendations to the developer.

This program is intended to be a useful resource for people working in or interested in the field of electrical and electronics engineering. We hope it will help users especially in understanding the basic concepts related to SMPS and power conversion, as well as in design and application topics. Below are the topologies we provide calculations for in the first version and their functions. If you do not have sufficient knowledge on the subject, please read:

- Buck converter is a power converter that steps down the input voltage to a lower output voltage. The program calculates and graphically displays current and voltage values based on input and output voltages.
- Boost converter is a power converter that steps up the input voltage to a higher output voltage. The program calculates and graphically displays current and voltage values based on input and output voltages.
- 2-Phase Interleaved Boost Converter is a power converter that converts an input voltage into a higher output voltage. The program calculates and displays current and voltage values ​​based on the input and output voltages.
- Inverting Buck-boost converter converts the input voltage to a negative or isolated voltage. The program calculates and graphically displays current and voltage values based on input and output voltages.
- Ćuk converter is a DC-DC power converter that can convert an input voltage into an output voltage with higher, lower, or reverse polarity relative to the input. The program calculates and graphically displays the current and voltage values ​​based on the input and output voltages.
- A Zeta converter is a DC/DC converter that can provide a positive output voltage that is higher, lower, or equal to the input voltage.
- SEPIC (Single-Ended Primary Inductor Converter) is a DC-DC power converter that can provide a positive output voltage higher, lower, or equal to the input voltage. The program calculates and graphically displays the current and voltage values ​​based on the input and output voltages.
- Flyback converter can provide several isolated output voltages. The program calculates and graphically displays current and voltage values based on input and output voltages.
- Single transistor forward converter can provide an electrically isolated voltage. The program calculates based on power values and voltage-current characteristics.
- Two-transistor forward converter provides an electrically isolated voltage at higher powers. The program calculates based on power values and voltage-current characteristics.
- Half-bridge push-pull converter provides an electrically isolated voltage up to a few KW. The program calculates based on power values and voltage-current characteristics.
- Full-bridge push-pull converter provides an electrically isolated voltage up to high KW values. The program calculates based on power values and voltage-current characteristics.
- Power factor pre-regulator is a switched-mode power supply for sinusoidal grid current. The program calculates for power factor correction and current-voltage balance.
- Inductor calculation section provides information about calculating the inductor L for maximum current I. The program calculates the inductance value with specific parameters.
- LLC full-bridge resonant converter is a power converter tuned to resonate at a specific frequency. The program calculates values such as resonance frequency and conversion efficiency.
- LLC half-bridge resonant converter is a power converter tuned to resonate at a specific frequency. The program calculates values such as resonance frequency and conversion efficiency.
- DAB (Dual Active Bridge) topology is an isolated DC-DC converter that provides bidirectional power transfer between two active bridges via a high-frequency transformer.
- The SAB (Single Active Bridge) topology is an isolated step-down DC-DC converter with an active full bridge on the primary and a diode bridge on the secondary, transferring power unidirectionally through a series (leakage) inductance.
- The Weinberg power topology is a switched-mode power supply (SMPS) circuit—particularly favored in aerospace and space applications—that utilizes coupled inductors and transformers integrated onto a single magnetic core to provide continuous input current, low electromagnetic interference (EMI), and high efficiency. The program performs calculations, analysis, and visualization for this topology.

***Note: Please click the 'Transformer data' and 'Coil data' buttons after entering the information and pressing the 'calculate' button. Otherwise, you may not get the correct coil and transformer recommendations. If there are transformers and coils that you think 'fit this topology', you can add them to the tables by entering the relevant information. This way, we aim to create our own database.

To reiterate; these programs are primarily written for those who know the basics of switched-mode power supplies. However, it should not be forgotten that the values given by the programs are based on general assumptions and different results can be obtained in real applications. Measurements and tests must be carried out for accurate and reliable results! Please use the programs after reaching a sufficient level of knowledge on the subject. In addition, make the necessary technical verifications on the results you obtain. When writing the programs, transistor control and some preventive measures (discharge sets, current limits) were not taken into account. The recommendations for ferrite cores are approximate values based on manufacturer tables as well as Keith Billings' book: Switch Mode Power Supply Handbook. In any case, check the specifications provided by us with the appropriate datasheets. Results can be downloaded in Excel format. You can also save the graphics as images or pdfs. This page will be continuously updated with new releases. Illustrated explanations are also planned for subsequent versions. Stay tuned.
